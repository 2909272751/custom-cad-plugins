# lbcp

AutoCAD 2021 梁表重排插件。

## 命令

- `LBCP`：按编号列的梁编号分类并按数字升序重排梁表文字行。
- `LBCPLOG`：查看最近一次运行日志路径。

## 使用流程

1. `NETLOAD` 加载 `lbcp-v0.1.1-autocad2021.dll`。
2. 输入 `LBCP`。
3. 框选需要整理的梁表范围。
4. 选择编号列中的一个梁编号文字，用来确定编号列。
5. 输入分类顺序，默认 `L,LL,KL,XL`。
6. 确认后执行重排。

## 第一版规则

- 只移动文字对象，不移动表格线。
- 表头不会移动：只有编号列能识别为梁编号的行才参与排序。
- 支持 `DBText` 和 `MText`。
- 梁编号示例：`L16(1)`、`LL1`、`KL22(1)`、`XL6`。
- 排序规则：先按分类顺序，再按编号数字升序。

## 日志

日志写入：

`%TEMP%\LBCP.log`
